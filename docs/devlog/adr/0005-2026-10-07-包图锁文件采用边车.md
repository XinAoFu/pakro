# ADR-0005 包图锁文件采用边车 mise.packages.lock

mise 主锁文件（mise.lock）是手写 TOML 读写器 + deny_unknown_fields + 版本合并机制，直接塞入包依赖图风险高；仓库已有边车先例（aube/uv 原生图旁挂目录）。决定：包解析图（RESOLVED graph：精确版本+哈希+依赖边）写入项目根的 `mise.packages.lock`（纯 serde TOML，分组键=运行时身份），格式稳定后（M5 评估）可再决定并回主锁。用户 2026-10-06 会话批准 M1 实现时采用此形态（见 log 偏差记录），本 ADR 补正式决策。

## Considered Options

| 候选             | 取舍                                                         |
| ---------------- | ------------------------------------------------------------ |
| 边车（选定）     | 零风险、可演进；代价是项目里多一个锁文件                     |
| 扩展 mise.lock   | 单文件体验；但需理解并侵入 9000+ 行手写锁机制，M1 风险不可控 |
| 无锁（每次重解） | 违反 SPEC FR-8 可复现性                                      |

## Consequences

- `mise install` 的锁复用逻辑读边车；未来并回时写迁移器 + 新 ADR 标注 Supersedes。
