# ADR-0006 锁文件统一策略

mise.packages.lock 边车与 mise.lock 主锁并存至 M5 结束；M5 内实现读双源（先主锁 [package] 表、后边车回退），写仍走边车（主锁的 TOML 编辑器需要深度理解才能安全扩展）。完整合并（写入主锁）推迟到上游 mise 团队审查边车格式稳定性后。

## Considered Options

| 候选 | 取舍 |
|---|---|
| 立即全部写入主锁 | 需侵入 9000+ 行手写 TOML 读写器；风险大于收益 |
| 边车永久化 | 多一个文件，用户体验差 |
| 读双源+写边车（选定） | 零风险；主锁自然演进时只需改写入路径 |
